# Plataforma de Delivery para Doceria

Sistema web desenvolvido para modernizar o processo de pedidos de uma doceria, permitindo que os clientes escolham produtos, personalizem as informações do pedido e finalizem a compra diretamente pelo site, com encaminhamento automático do pedido para o WhatsApp da loja.

O projeto também conta com um painel administrativo para facilitar o gerenciamento do catálogo de produtos e a manutenção da plataforma.

## Sobre o projeto

A proposta da plataforma é simplificar a experiência de compra dos clientes e tornar o atendimento da doceria mais organizado e eficiente.

Por meio de uma interface intuitiva, o cliente pode visualizar os produtos disponíveis, informar seus dados, escolher entre delivery ou retirada no local e selecionar a forma de pagamento. Ao finalizar o pedido, o sistema prepara e encaminha automaticamente as informações para o WhatsApp da loja, facilitando a continuidade do atendimento.

Além disso, a plataforma possui um painel administrativo que permite à responsável pela doceria gerenciar os produtos disponíveis no catálogo.

## Funcionalidades

### Área do cliente

- **Catálogo digital:** visualização dos produtos disponíveis na doceria.
- **Seleção de produtos:** escolha dos itens desejados para o pedido.
- **Identificação do cliente:** preenchimento do nome para identificação do pedido.
- **Modalidade de recebimento:** opção entre delivery e retirada no local.
- **Forma de pagamento:** seleção da modalidade de pagamento desejada.
- **Finalização de pedido:** organização das informações do pedido para envio.
- **Integração com WhatsApp:** encaminhamento automático do pedido para o WhatsApp da loja após a finalização.

### Painel administrativo

- **Gerenciamento de produtos:** administração do catálogo da doceria.
- **Adição de produtos:** cadastro de novos itens disponíveis para venda.
- **Remoção de produtos:** exclusão de itens que não devem mais aparecer no catálogo.
- **Manutenção do catálogo:** atualização dos produtos conforme as necessidades do negócio.

## Objetivo do projeto

Desenvolver uma solução digital acessível e funcional para facilitar a realização de pedidos, reduzir a dependência de atendimentos manuais e oferecer à doceria uma maneira mais prática de apresentar seus produtos e receber solicitações de compra.
